# Checklist manual do novo storefront

- Abrir a home em viewport mobile.
- Ir até o cardápio.
- Adicionar um produto disponível.
- Confirmar que a barra flutuante aparece com quantidade e total.
- Tocar em `Ver pedido →`.
- Confirmar abertura do carrinho como bottom sheet.
- Avançar ao checkout e preencher os dados atuais exigidos pelo backend.
- Gerar Pix e confirmar que o fluxo existente continua funcional.
- Remover todos os itens e confirmar que a barra flutuante desaparece.
